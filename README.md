## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.

## Design References

### Buscador

![Captura buscador web viajes](./docs/design-references/Captura buscador web viajes.png)
Referencia para la estructura del buscador en bloque principal: jerarquia clara entre destino, fechas y accion primaria de buscar.

![Captura buscador web viajes 2](./docs/design-references/Captura buscador web viajes 2.png)
Referencia para una variante de layout con filtros visibles y mejor distribucion horizontal de campos en pantallas amplias.

### Hero de la Home

![Captura hero index](./docs/design-references/Captura hero index.png)
Inspira la composicion del hero con titular protagonista, texto de apoyo y fondo visual inmersivo que dirige la atencion al buscador.

### ProductCard de experiencias

![Captura productcard experiencias](./docs/design-references/Captura productcard experiencias.png)
Referencia para la tarjeta de experiencia: equilibrio entre imagen, titulo, metadatos y llamada a la accion en una sola pieza compacta.

![Captura productcard experiencias espacio](./docs/design-references/Captura productcard experiencias .png)
Referencia para ajustes de tipografia y espaciado interno en cards, priorizando legibilidad de precio, categoria y valoraciones.

### Pagina de detalle

![captura pagina detalle 2](./docs/design-references/captura pagina detalle 2.png)
Referencia para la vista de detalle con foco en layout por secciones, bloque de informacion clave y ritmo visual entre contenido e imagen.
